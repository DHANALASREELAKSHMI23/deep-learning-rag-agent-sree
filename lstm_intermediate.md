# Long Short-Term Memory

Long Short-Term Memory, or LSTM, is a type of recurrent neural network designed to handle long-term dependencies in sequential data.

LSTMs use gating mechanisms to control information flow. The main gates are the input gate, forget gate, and output gate.

The forget gate decides what information should be removed from the cell state. The input gate decides what new information should be stored. The output gate controls what information is passed to the next hidden state.
